# یادداشت حقوق و مجوزها

این فایل مجوز نرم‌افزاری یا اجازهٔ انتشار صادر نمی‌کند.

- مجوز متن‌باز یا حقوق مالکیت کد پروژهٔ ورودی در فایل‌های آن مشخص نشده است. پیش از انتشار، صاحب حقوق باید مجوز مناسب کد را تعیین کند. آماده‌سازی فنی برای GitHub به معنی متن‌بازشدن پروژه نیست.
- مجوز بازتوزیع عمومی و استفادهٔ تجاری فایل‌های `music/track_01.mp3` تا `music/track_12.mp3` تأیید نشده است. نام منابع اولیه در `music/SOURCES.txt` است؛ نام فایل به‌تنهایی مدرک مجوز نیست. برای هر آهنگ، متن مجوز و اجازهٔ بازتوزیع را از منبع معتبر دریافت کنید.
- مجوز فونت موجود در `fonts/LICENSE.txt` باید همراه فونت حفظ شود.
- صدای `sounds/star.wav` برای این اصلاح با ترکیب موج سینوسی تولید شده و نمونه‌ای از موسیقی‌های موجود نیست. این توضیح به‌خودی‌خود مجوزی برای سایر دارایی‌ها یا کل پروژه صادر نمی‌کند.
- Godot برای اجرا لازم است اما فایل اجرایی موتور داخل این مخزن بسته‌بندی نشده است.

تا زمان روشن‌شدن حقوق، از انتشار عمومی یا تجاری دارایی‌های دارای مجوز نامشخص خودداری کنید.
