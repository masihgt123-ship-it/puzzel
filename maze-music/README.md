# Maze Music — پروژهٔ Godot

بازی هزارتوی ۵۰مرحله‌ای برای Godot 4.4.1، با رابط فارسی، کنترل لمسی و ۱۲ آهنگ کامل. این مخزن **پروژه است، نه APK**.

> **هشدار انتشار:** حقوق انتشار عمومی و مجوز تجاری آهنگ‌ها تأیید نشده است. پیش از عمومی‌کردن مخزن، مجوز بارگذاری و بازتوزیع هر ۱۲ فایل را بررسی کنید. خصوصی‌بودن مخزن نیز جایگزین دریافت مجوز لازم نیست. این بسته مجوز متن‌باز تازه‌ای برای کل پروژه تعیین نمی‌کند؛ [یادداشت مجوزها](LICENSE-NOTICE.md) را بخوانید.

## اجرا
1. Godot 4.4.1 را نصب کنید.
2. `project.godot` را باز کنید و اجازه دهید منابع Import شوند.
3. با F5 اجرا کنید.

## رفتار فعلی
- بازی در هر اجرای تازه از مرحلهٔ ۱ آغاز می‌شود؛ پیشرفت بین اجراها ذخیره نمی‌شود.
- از مرحلهٔ ۵ تا ۵۰، گرفتن هر دو ستاره شرط بازشدن خروج است.
- ستاره‌ها روی مسیر معتبر شروع تا خروج قرار دارند؛ راهنما ابتدا ستاره‌ها و سپس خروج را نشان می‌دهد.
- از مرحلهٔ ۷، یک تعقیب‌کننده پس از ۵ ثانیه فعال می‌شود و تدریجاً سریع‌تر می‌شود.
- در هر مرحله آهنگ عوض می‌شود؛ ۱۲ آهنگ به‌ترتیب تکرار می‌شوند.
- عنوان بالای صفحه و متن مرحله، حرکت و زمان نمایش داده نمی‌شوند.
- مه، موجود دوم و توقف سه‌ثانیه‌ای هنوز پیاده‌سازی نشده‌اند.

## بارگذاری در GitHub
پس از بررسی مجوز فایل‌ها، مخزن خالی بسازید و **محتویات این پوشه** را بارگذاری کنید؛ `project.godot` و این README باید در ریشهٔ مخزن باشند. اگر فقط می‌خواهید پروژه را نگه دارید، مخزن خصوصی انتخاب کنید و فایل‌های دارای حقوق نامشخص را عمومی نکنید.

یا در ترمینال، داخل همین پوشه:
```bash
git init -b main
git add .
git commit -m "Prepare Godot maze project"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```
نشانی نمونه را با نشانی مخزن خود جایگزین کنید. برای Push باید دسترسی GitHub را روی دستگاه خود تنظیم کنید. در این بسته هیچ توکن، فایل APK، پوشهٔ `.git` یا کش `.godot` قرار ندارد. این پروژه از طرف شما در GitHub بارگذاری نشده است.

## آزمون خودکار
پس از Import:
```bash
godot --headless --path . --script res://tests/verify.gd
```
گردش‌کار `.github/workflows/godot-tests.yml` همین آزمون را در GitHub Actions اجرا می‌کند. **خود گردش‌کار هنوز روی GitHub اجرا نشده است**؛ آزمون محلی همین نسخه در Godot اجرا شده است.

گزارش در `tests/results.json` است. آزمون‌ها اتصال نقشه، مسیر ستاره‌ها، قفل خروج، راهنما، شروع مجدد، برخورد، ۱۰۰ حل زمان‌بندی‌شدهٔ مراحل و انتخاب/شروع موسیقی را بررسی می‌کنند. آزمون headless جای تست گوشی، مشاهدهٔ ظاهر یا شنیدن واقعی موسیقی را نمی‌گیرد.

جزئیات آزمون‌ها، محدودیت‌ها و روش بازی: [راهنمای فارسی](README-fa.md).

## ساختار
- `main.gd` و `main.tscn`: منطق و صحنهٔ بازی
- `stage_music.gd`: انتخاب و تکرار آهنگ
- `music/`: هر ۱۲ آهنگ اصلی و فهرست منابع
- `sounds/star.wav`: صدای تولیدشدهٔ دریافت ستاره
- `fonts/`: فونت و مجوز آن
- `tests/`: آزمون اجرایی و گزارش
